FIGlet fonts bundled with glyphsaver. All render through the built-in
`ascii` renderer — no `figlet` binary required.

- omarchy.flf — the true Omarchy wordmark font: glyphs O m a r c h y
  pixel-extracted from the Omarchy `logo.txt` (renders `Omarchy`
  byte-identical), remaining A–Z 0–9 and basic punctuation hand-drawn in
  the same 10-row block style (unicase).
- Delta-Corps-Priest-1.flf — block display face, usable via
  `ascii --font Delta-Corps-Priest-1` (kept for compatibility).
- big, block, bubble, digital, mini, script, shadow, slant, small,
  standard — stock FIGlet 2.2.5 fonts (see `figlet -l`), freely
  redistributable, included so every style works out of the box.

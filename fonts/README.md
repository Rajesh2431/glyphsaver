FIGlet fonts bundled with glyphsaver. All render through the built-in
`ascii` renderer — no `figlet` binary required.

- Delta-Corps-Priest-1.flf — the Omarchy wordmark font (letters + space),
  from basecamp/omarchy `bin/omarchy-ascii`, extended here with hand-drawn
  digits 0-9 in the same 9-row block style.
- big, block, bubble, digital, mini, script, shadow, slant, small,
  standard — stock FIGlet 2.2.5 fonts (see `figlet -l`), freely
  redistributable, included so every style works out of the box.
